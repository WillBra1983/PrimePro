# Suporte — PrimeProFast

**PrimeProFast** é a calculadora nativa de números primos (Android e iOS), com motor C++/GMP no dispositivo.

## Como pedir ajuda

1. **GitHub Issues (recomendado)**  
   Abra uma issue em:  
   **https://github.com/WillBra1983/PrimePro/issues**

   Escolha o modelo **“Suporte / dúvida”** e descreva:
   - Plataforma (Android ou iOS) e versão do app
   - Modelo do aparelho e versão do sistema
   - O que você tentou fazer e o que aconteceu (mensagem de erro, se houver)

2. **E-mail**  
   **prwilsonlucas@gmail.com**  
   Assunto sugerido: `PrimeProFast — suporte`

## Perguntas frequentes

**O app precisa de internet?**  
A maior parte dos cálculos funciona **offline**, no próprio aparelho.

**Meus números são enviados a algum servidor?**  
Não para fins de cálculo. Os dados que você digita são processados **localmente**. Veja a [Política de Privacidade](PRIVACY_POLICY.md).

**Onde ficam os arquivos exportados?**  
- **Android:** pasta Downloads/PrimeProFast (ou visualizador temporário após o cálculo)  
- **iOS:** visualizador do sistema; arquivos salvos em Arquivos → PrimeProFast

**iOS — build / TestFlight**  
Desenvolvimento e releases: repositório [WillBra1983/PrimePro](https://github.com/WillBra1983/PrimePro).
