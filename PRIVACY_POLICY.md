# Política de Privacidade - PrimeProFast

**Última atualização:** 15 de dezembro de 2024

## 1. Informações Gerais

O PrimeProFast é um aplicativo de calculadora de números primos desenvolvido para fins educacionais e de pesquisa matemática. Esta política descreve como coletamos, usamos e protegemos suas informações.

## 2. Coleta de Dados

### 2.1 Dados NÃO Coletados
- **Nenhum dado pessoal** é coletado pelo aplicativo
- **Nenhuma informação** é enviada para servidores externos
- **Nenhum dado** é compartilhado com terceiros
- **Nenhuma informação** de identificação pessoal é armazenada

### 2.2 Dados Processados Localmente
- Números inseridos pelo usuário para cálculos matemáticos
- Resultados de cálculos de números primos
- Configurações do aplicativo (tema, preferências)
- Arquivos temporários gerados durante os cálculos

## 3. Uso dos Dados

Todos os dados processados pelo aplicativo são:
- **Processados localmente** no seu dispositivo
- **Usados exclusivamente** para realizar os cálculos matemáticos solicitados
- **Armazenados temporariamente** apenas durante a sessão de uso
- **Excluídos automaticamente** quando o aplicativo é fechado

## 4. Armazenamento e Segurança

### 4.1 Armazenamento Local
- Os dados são armazenados apenas no seu dispositivo
- Nenhum backup automático é realizado
- Os arquivos temporários são limpos automaticamente

### 4.2 Segurança
- Todos os cálculos são realizados localmente
- Nenhuma conexão de rede é estabelecida para processamento
- Os algoritmos são transparentes e auditáveis

## 5. Permissões do Aplicativo

### 5.1 Permissões Utilizadas
- **INTERNET**: Para verificar atualizações (opcional)
- **ACCESS_NETWORK_STATE**: Para verificar conectividade
- **WRITE_EXTERNAL_STORAGE**: Para salvar resultados (Android 10 e anteriores)
- **READ_EXTERNAL_STORAGE**: Para acessar arquivos salvos (Android 10 e anteriores)
- **READ_MEDIA_IMAGES/VIDEO/AUDIO**: Para acessar mídia (Android 13+)

### 5.2 Uso das Permissões
- As permissões são usadas apenas para funcionalidades do aplicativo
- Nenhum dado é enviado para servidores externos
- Os arquivos são salvos apenas no armazenamento local

## 6. Compartilhamento de Dados

- **Nenhum dado** é compartilhado com terceiros
- **Nenhuma informação** é vendida ou comercializada
- **Nenhum dado** é usado para publicidade
- Os resultados podem ser exportados pelo usuário (opcional)

## 7. Retenção de Dados

- Os dados são mantidos apenas durante o uso do aplicativo
- Arquivos temporários são excluídos automaticamente
- Configurações do usuário são mantidas localmente
- Nenhum dado é retido após a desinstalação do aplicativo

## 8. Direitos do Usuário

Você tem o direito de:
- **Acessar** todos os dados processados pelo aplicativo
- **Excluir** qualquer arquivo gerado pelo aplicativo
- **Desinstalar** o aplicativo a qualquer momento
- **Não fornecer** dados desnecessários

## 9. Menores de Idade

O aplicativo é adequado para todas as idades e não coleta dados de menores de 13 anos. Todos os cálculos são realizados localmente sem coleta de informações pessoais.

## 10. Alterações na Política

Esta política pode ser atualizada ocasionalmente. As alterações serão publicadas nesta página com a data de atualização.
